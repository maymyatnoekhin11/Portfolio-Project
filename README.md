# AI Tools Portfolio Project

---

## Research Topic
**LinkedIn Organic Content Strategy for B2B SaaS**

This repository demonstrates independent research, AI-assisted data collection, and GitHub project organization.

I selected this topic because LinkedIn is one of the most important channels for B2B SaaS marketing. I wanted to understand how leading practitioners build audiences, establish thought leadership, and generate business opportunities through organic content.

---

## Research Methodology
- Identified 10 experienced B2B SaaS marketers and content creators.
- Collected and analyzed recent LinkedIn posts from each expert.
- Used the Supadata API to retrieve YouTube transcripts from selected expert videos.
- Organized all research materials into structured folders for future analysis.

---

## Technical Implementation

### API Usage
To demonstrate technical research skills, I used the Supadata API to programmatically retrieve YouTube transcripts from selected experts. The transcripts were stored in the `/research/youtube-transcripts/` directory for further analysis.

---

### Repository Structure
- `/research/sources.md` — Expert profiles, source links, and annotations.
- `/research/linkedin-posts/` — LinkedIn post analyses organized by author.
- `/research/youtube-transcripts/` — YouTube transcript files retrieved through API and summarized.
- `/research/other/` — Additional reports and supporting materials.

---

## Key Research Goals
- Identify common LinkedIn content patterns among successful B2B SaaS practitioners.
- Understand audience-building and personal branding strategies.
- Explore how content supports demand generation and pipeline growth.

---

## Environment Setup
- Cursor IDE (macOS)
- Claude and Codex models in Cursor
- GitHub for version control and repository management

---

## Preliminary Findings
- Consistency is a major factor in audience growth.
- Educational content performs better than promotional content.
- Storytelling and personal experiences drive engagement.
- Successful creators frequently repurpose content across multiple channels.
- Strong personal brands support demand generation and lead acquisition.
